# 会话草稿设计

## 草稿状态

铅笔表示会话有未发送的草稿。即使用户已经离开输入框，只要还有草稿，这个状态就会保留。

插件通过 `conversation.input.overlay` 的 `useInput` 按会话 ID 记录输入框中是否有非空白文字。
引用会随编辑器的文字表示计入。
恢复页面时，插件按 DeepSeek Harness 0.2.2-rc.5 的 `readConversationDraft` 格式只读浏览器原生草稿存储，
兼容纯字符串和结构化草稿。
存储不可用时，可继续跟踪当前页内的输入。

插件仅公布会话 ID 集合作为可选 Client 服务 `sessionDraftIndicators`，供侧栏标记和三态插件订阅。
三态插件随服务启用或停用自动接入或取消订阅。

## 侧栏状态图标

DSH 0.2.2-rc.5 的原生图标集中，语义最接近的是用于发起编辑的图标，
例如会话菜单中「重命名」动作使用的 `IconEditOutlineRegular`。
原生图标没有专门表示「有未发送草稿」的状态标记，因此插件使用自绘的铅笔 SVG。
铅笔只提示状态，不提供编辑操作，使用主题次级文字色和本地化辅助标签。

`sidebar.session.row.leading` 由原生会话行选择渲染，因此状态优先级由 DSH 控制。
原生定时任务时钟出现时已占满 16px 插槽，铅笔让出位置，草稿仍计入「需关注」。
